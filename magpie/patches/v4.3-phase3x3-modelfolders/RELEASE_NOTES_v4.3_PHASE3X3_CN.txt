Magpie GameSR v4.3 - Phase-Aware 3x3 与模型子文件夹

1. 基于 v4.2.6 全模型输入/输出 SIMD 版本，保留 SIMD、当前 720p 直进 NPU和异步三槽流水线。
2. O3 继续使用旧 RGB residual，不要求 decoder.json。
3. O4/O6/O8 同时支持：
   - 旧 bilinear_then_1x1 decoder（O*3 权重、3 bias）；
   - 新 phase_aware_3x3_v1 + rgb_residual schema v3
     （9 phase * 3 RGB * O * 3 * 3 权重、27 bias）。
4. 新 decoder 参数上传到 D3D11 StructuredBuffer，HLSL 按 3/2 输出坐标选择九相位，
   使用 replicate 边界读取 720p latent 的 3x3 邻域，最后与 1.0x bilinear source 相加。
5. models\GameSR 可建立任意层级子文件夹。选择器显示并保存相对路径；旧版直接堆放在
   models\GameSR 根目录的配置继续有效。禁止绝对路径和 .. 越界。
6. 首帧等待 NPU 时使用独立 baseline shader，decoder bias 不会污染双线性占位帧。

推荐目录：
models\GameSR\模型名称\
  模型名称-int8-qdq.onnx
  模型名称-int8-qdq.onnx.meta.json
  模型名称.onnx.decoder.json
