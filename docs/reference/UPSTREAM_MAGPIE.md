## 为什么单独索引

GameSR 仓库中的 `docs/archive/` 主要记录我们自己的训练、NPU 部署和性能实验。Magpie 的通用手册更新节奏独立，直接复制进 GameSR 当前规范容易造成版本混淆，因此这里保留来源和文件索引；需要核对 Magpie 通用行为时，应以对应上游版本文档为准。
